# Athens Airbnb Market Analysis
This project analyzes the Airbnb market in Athens, exploring pricing trends across neighborhoods. Using data from Inside Airbnb, I built an interactive Tableau dashboard. The project follows the methodology from Alex the Analyst's "Full Beginner Project in Tableau," adapted to Greek data.

## Dashboard description
The dashboard includes three bar charts: "Average Price by Neighbourhood" which shows the average price per area, "Average Price by Room Type" which shows the average price for each type of accommodation and "Total Listing Price by Neighbourhood" which shows which neighbourhood has the highest combined listing prices. Although it might seem useless at first, it's actually not, the total listing price combines both the number of listings and their prices, so it reflects the overall size of the Airbnb market in each area, not the actual revenue since listings may remain unbooked. It shows where there is more overall activity, whether that comes from having many listings, higher prices, or both. The dashboard also includes two maps, where the color coding helps the reader identify the location of each neighbourhood, and a second map (in blue) provides a clearer sense of average prices per neighbourhood, with darker shades indicating higher average prices. It is worth noting that the Rigillis area was excluded from this analysis, as it contained only 4 observations and acted as an outlier.
